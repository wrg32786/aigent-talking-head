# aigent-talking-head v1.27.2

Fixes "Wizards failed to fetch" from a live test on Windows.

## What is fixed

- **Studio says when it stopped.** If Studio stops while the page is open, we now show a Studio stopped bar instead of "Failed to fetch" on every click. Copy for my agent gives your agent what it needs to start Studio again, and the page reconnects by itself.
- **Wizards load again.** The Wizards sheet has Try again, and loads on its own when Studio is back.
- **Copy a reference opens the right screen.** It showed the clips screen before. Now it asks for the reel link.
- **Studio keeps running after a background error.** An error in a download or breakdown is written to the log instead of stopping Studio.

## Update

Tell your agent "Update aigent-talking-head and restart Studio".
