# aigent-talking-head v1.30.0

A long talk can now become the take for a reel, and a finished reel comes with a cover, post copy and a ZIP you can post yourself.

## Highlights on Start

- Drop in a long talk or podcast (about 3 minutes or longer). We transcribe it on your computer and suggest up to 10 complete moments, each with a reason and a start time.
- Moments never start or end mid-word or mid-sentence. The ones you tick become the take, already cut, and you move on to Cut.
- Copy the brief for your agent, or use `find_highlights`, `get_highlights`, `score_highlights` and `pick_highlights`. The local scores are the fallback when no agent scores them.

## Publish kit on Render

- After a reel is rendered, a card makes a cover still with the title kept off your face, post copy (title, description and hashtags) for each platform, and a ZIP with the reel, the `.srt`, the cover and the copy, all beside the reel.
- Nothing is posted for you. Copy the caption, or download the ZIP. Agents: `get_publish_kit`, `set_post_copy`, `make_publish_kit`.
- **Post it** still opens Buffer drafts only.

## How it compares

The README now names [AutoClip](https://github.com/zhouxiaoka/autoclip) (MIT) as the closest open-source neighbor: it finds highlight clips in a long podcast or talk, then packs each one with a cover and post copy. We start from one talking-head take and finish the reel. The idea is credited in THIRD_PARTY.md. No AutoClip code is included.

## Fixes

- A teardown keeps going when a caption word sits entirely on the person, or when extras.json cannot be read.
- Instagram download errors print a plain refusal, not a traceback.
- If your old B-roll library is a link to another drive, the Vault stays next to that real folder, and the move prints the exact destination. An existing kit vault is left in place. A scratch Studio session does not move the install's library; set STUDIO_VAULT or the Vault folder in Settings to keep using the install vault.
- `npm run setup:all` no longer warns on Node 24, and it ends with a line to restart Studio if it is already running.
