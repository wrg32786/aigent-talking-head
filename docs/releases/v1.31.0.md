# aigent-talking-head v1.31.0

Studio has a new guided builder you can use without an agent in the terminal. You can also paste a GitHub link and we will build a repo feature video from the pictures already in that README.

## A guided builder in Studio

- Studio now has three areas: New video, Teardowns, and Recording. Recording is its own section, not the first step of a new video.
- New video walks you through one choice at a time: pacing, how text comes in, where it sits, ordinary captions or kinetic text, colors, fonts, and (when you pick kinetic text) larger keywords. You see a combined preview of your text choices, then lock that section and move on to transitions, presenter effects, filters (including black and white, and when they show), your notes for the agent, and music last.
- Teardowns is its own area, with your template library. You can start from a saved template or build a custom one in the guided flow, and you can save a look from a finished plan.
- Before we make the video, we check your plan against the choices you made.

## Repo feature mode

- Paste one to three GitHub links. We use the images and GIFs from each README as B-roll. If a repo has none, we show the README itself. The repo sits in a rounded card on the top half, captions run through the middle (kept off your face), and you sit in a rounded box at the bottom with your head breaking above the top edge.
- Frame breakout is on by default in this mode. You can turn it off. Every few seconds the repo can take over the full screen for two to five seconds, and the pictures change every two to four seconds. A template can change those timings and the layout.
- The Template Library includes a starter called Repo feature (breakout), with word-by-word captions. It waits for a GitHub link before Make or Render will run.

## Also since v1.30.0

- The README hero is now the Studio ad.
- Verify counts flashes in the finished reel, including a strobe on every frame and halves that flip against each other. More than three flashes in a second fails.
- The person mask crops more tightly around you so fine hair has more detail, checks free memory before it runs, and can flag a patch of the matte that looks like the room.
- Style packs can set caption outline and split placement.

## Known gaps

- Fable has not reviewed this release. Any fixes from that review will go out as v1.31.1 or a later v1.31.x.
- Repo mode uses visuals already in the README. It does not generate new B-roll from the repo.
- A persistent headline with a highlighted keyword can be saved on the plan, but it is not drawn yet.
- These publish kit bugs from v1.30.0 are still open: remaking the kit can lose post copy you edited; saving copy from a platform with a short limit can shorten the description for every platform; the warning about a face under the cover title never shows.

## Update

In your copy of the kit: `git pull`, then `npm run setup:all` (it only installs what is missing). Or tell your agent "Update aigent-talking-head". If Studio is already running, restart it.
