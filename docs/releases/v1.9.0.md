# aigent-talking-head v1.9.0

Cuts land in the right place now. Every way the kit cuts your footage uses one set of rules that listens to the audio, so a word is never clipped at the start or cut off at the end.

## What is new

- **No more cut-off words.** Draft clips, the Cut step, Lines, One clean take, Bites, bite renders and tightening all place their cuts the same way. On a 5.5 minute test take, 42 of 390 cuts used to land inside a word. Now it is 0 of 484.
- **Room to breathe at every cut.** Each piece starts a little over a tenth of a second before the first word and ends about a fifth of a second after the last sound. A soft "s" or "th" at the end of a word counts as speech, so it is not chopped.
- **No pause, no cut.** When you run one sentence straight into the next, the cut waits for the next real pause instead of cutting a word in half.
- **Tightening that listens.** Tightening the draft only removes the quiet between words and keeps the breath around them.
- **What you cut is what you get.** Rendering from the Cut step or a bite now uses exactly the pieces you made, instead of cutting the footage again.
- **One transcript.** The draft and Studio now share one transcript that skips long silences, so a stretch of room tone is never read as a word.
- **Check your own footage.** `node kit/cut-bench.mjs take.mp4 --words take.tx.json` shows, for every way of cutting, how many cuts land in a word and how much room each cut has.

## Update

In your copy of the kit: `git pull`, then `npm run setup:all` (it only installs what is missing). Or tell your agent "Update aigent-talking-head and run npm run setup:all". Studio redoes transcripts made before this version the next time you open the footage.
