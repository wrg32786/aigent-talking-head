# aigent-talking-head v1.31.1

Repo videos look better, a Teardowns look library, a person mask that fits on modest machines, and the fixes from the Fable review of v1.30.0 and v1.31.0.

## Repo feature mode

- The repo B-roll stays in its card. It never cuts to full screen, never shows plain text, and never shows the README page as a shot. Render refuses a cut that would break that rule, and Plan check has a row for it.
- When a README has few pictures, we make short animated window cards from the README and the repo's facts (the repo page, a terminal with the real clone and files, a feature wheel, topics, a flow, stars). A good README gets its own pictures, each in a window card. They are made offline on your computer.
- The cards have a 3D camera: the window flies in, settles, then orbits slowly, with depth, shadows and a light sweep. CSS only.

## Teardowns look library

- Save a broken-down video as a look, combine parts from different videos or saved looks (captions from one, the grade from another), and rename, duplicate or delete looks.
- Each look gets a short sample, made on your computer from the kit's sample presenter and a fixed script, never the reference's words.
- After a breakdown, six layers (Set, Person, Layout, B-roll, Type, Motion) show what we measured. Reduced motion shows a simple list.

## Modest machines

- On Windows, the high-quality person mask uses the processor when the graphics chip does not fit (slower, same quality), and Studio says so before you click Render. Overlay render and the transcript use less memory when it is tight.

## Fixes

Publish kit and Highlights:
- Make again keeps the post copy you edited.
- Saving copy from a platform with a short limit no longer shortens the description on every platform.
- The note about the cover title sitting near your face now shows, and it is measured on the letters as drawn. The cover preview updates after Make again.
- Descriptions keep their line breaks.
- Only 9:16 reels get a kit (the effects version and the smaller 9:16 copies too), never a stretched 4:5 or 1:1 cover.
- A highlight your agent times by start and end keeps its small pause, does not pull in the next sentence, and keeps your tick. An old Highlights error clears.

Repo mode and Render:
- Edit this reel, then Render, keeps the repo cards. The words of each clip are now kept with the saved version.
- Studio no longer puts a made card from another video on this one. In repo mode it places no text card on its own.
- Repo mode with no repo pictures still keeps B-roll off full screen. Turning repo mode off puts your B-roll back full screen.
- A repo with "badge" or "shield" in its name keeps its pictures. The terminal card only types shell commands.
- Plan check: one round still fixes things, it remembers the plan it checked and asks you to check again after you change it, and a size export no longer makes the reel look out of date.
- Low memory goes on the reel step. Studio's log no longer shows terminal flags.

Look library:
- The look sample is as long as its plan (about 9 seconds, it was about a minute) and much faster to make. An out-of-date sample says so and has a Remake button.
- A mixed look now draws with the parts you picked, not the first look's style.
- Combine never replaces a saved look, and an uploaded reference works as a source.
- Deleting a look that a saved template uses is refused, with the reason.
- The layer view counts every graphic.

## Known gaps

- Titles can still sit over the repo card during a split. That needs render work and will come later.
- Studio's flow is still being redesigned: Use buttons on looks, a single start screen and the order of steps are not in this release.
- Repo mode uses what is in the README and the repo's facts. It does not generate new footage.

## Update

In your copy of the kit: `git pull`, then `npm run setup:all` (it only installs what is missing). Or tell your agent "Update aigent-talking-head". If Studio is already running, restart it.
