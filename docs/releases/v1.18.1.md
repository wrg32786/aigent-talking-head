# aigent-talking-head v1.18.1

Uploading a new video in Studio starts a fresh edit, Finish shows only the current draft, and you can clear all B-roll from the timeline.

## What is new

- **A new upload starts a fresh edit.** When you drop or choose a new talking-head file on a board that already has an edit, Studio clears the cuts, pieces, B-roll, reference and draft. The look resets too, unless you chose **Keep my look** in **New video**. Files are never deleted. Earlier reels stay in Outputs, and **Open a past video** still opens your other jobs. Use **New video** if you want the new take as its own job.
- **Finish shows only the current draft.** Draft, Check and Render never play a render from another draft or take. If there is no video yet, you see the plan or a fast preview of this draft's cuts. Show original only compares a reel that was rendered from this draft. Earlier reels stay in Outputs, each with its player, date, source take and draft, **Edit this reel**, and **Download**.
- **The leftover B-roll is gone.** The B-roll step was still showing spots from the last video after you uploaded a new one, because it kept reading the old draft on disk. That leftover draft is now ignored until you draft again.
- **Clear all B-roll.** On the B-roll step, **Clear all B-roll** takes every clip off the timeline (it asks first). **Undo** puts them back. Your library is unchanged.
- **Your agent can do it too.** New tool `clear_broll`. `fill_slot` with `clear` and `all` does the same.
