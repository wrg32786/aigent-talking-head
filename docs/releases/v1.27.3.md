# aigent-talking-head v1.27.3

macOS fixes, with thanks to @mmjohnson84BMP for #70.

## What is fixed

- **Folder tests pass on a Mac.** Studio's folder picker tests now know the Mac video folder is Movies. Thanks @mmjohnson84BMP.
- **A clear message when ffmpeg cannot draw text.** Homebrew's plain ffmpeg has no drawtext filter, so titles could not render. Smoke now says so right away, and the Mac install docs point to ffmpeg-full. Thanks @mmjohnson84BMP.
- **Setup check spots it too.** Studio's Setup check now flags an ffmpeg without drawtext, or one that no longer starts, and Copy for my agent gives your agent the exact fix.
