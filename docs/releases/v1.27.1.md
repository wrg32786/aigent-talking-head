# aigent-talking-head v1.27.1

Fixes from a final review of Recreate.

## What is fixed

- **Recreate never gets stuck on a reference.** If breaking down a reference file failed or Studio was restarted mid-way, Draft used to wait for it forever. Now you can draft or try the file again.
- **Queued links start on their own.** A reference link still in the queue when Studio restarts now starts downloading.
- **Clearer reasons.** When the reference has no glitch, each cut says "hard cut (glitch off)" instead of the glitch default.

## Update

Tell your agent "Update aigent-talking-head and restart Studio".
