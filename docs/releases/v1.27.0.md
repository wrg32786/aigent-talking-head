# aigent-talking-head v1.27.0

Tidier insides for Recreate. Nothing changes in how you use Studio.

## What is new

- **Smaller pieces.** The code that turns a teardown into a recipe is now ten small parts, one per job: captions, titles, graphics, grade, music, colours, scenes, the recipe and the report.
- **One place for Recreate.** Everything Recreate does to a draft lives in one module, so a fix lands once.
- **One plan per draft.** Each Recreate draft saves a plan of its shots, transitions, moves, sounds, scenes and colours. B-roll spots read it, and your agent can too.

## Update

Tell your agent "Update aigent-talking-head and restart Studio".
