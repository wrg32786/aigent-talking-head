# aigent-talking-head v1.23.0

Using a reference is calmer and clearer.

## What is new

- **One choice, the same words everywhere.** Recreate, Influence or Off, with one line saying what each does.
- **A smaller reference card.** Its name, length and shots, and your choice. Save as a Look, Clear reference and Breakdown sit under More.
- **See what Recreate brings at a glance.** Small chips for its shots, framing, cutaways, sounds and music, and "made for you", which opens the effects Studio made from it.
- **Recreate comes first.** On Recreate the reference card sits above the Looks, which dim because the reference sets them.
- **A shorter Breakdown.** The numbers, the shot timeline and the contact sheet are under Details. A note about anything we could not read shows only when it matters.
