# aigent-talking-head v1.25.0

Recreate a video from the first screen, and a calmer Look step.

## What is new

- **Recreate from the start.** On Footage, choose "Recreate a video", paste a link or add a file, and keep going while we read it.
- **See why.** Each layer on the Look step says what the reference picked and why. Hover a tile for its reason.
- **Clear labels.** "From reference" marks an option the reference picked. "Made for you" marks an effect or graphic we made from it.
- **Less clutter.** Your picks sit behind one count, grouped by layer. The More menu keeps only what is not already on the page.
- **No more waiting on links.** Draft and Render work while reference links download. If Recreate still needs the reference, Studio tells you.

## Update

Tell your agent "Update aigent-talking-head and restart Studio".
