# aigent-talking-head v1.26.0

B-roll like the reference, and a remake that keeps your face clear.

## What is new

- **B-roll that matches.** Each B-roll spot from a reference knows how long the reference's cutaway ran and what it showed, so the search and the suggested clip match it.
- **No surprise glitches.** A remake only glitches between shots when the reference does. Camera shakes from the reference stay.
- **Truer colours.** The colours of the reference's graphics now count when we pick its accent.
- **Your eyes stay clear.** A screen card or graphic that would cover your face moves down to your chin and shrinks a little if needed.
