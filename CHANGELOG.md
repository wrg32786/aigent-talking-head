# Changelog

## 1.2.0 (unreleased)

Edit rules from the Muse reel workflow, plus parts of a motion design pack, adapted to 1080x1920 at 24 fps.

- **Cinematic SFX pack.** 31 Will-approved sounds in `kit/sfx/` (`sfx.json`), all CC0. `npm run fx` auto-picks one per effect hit (category map, no-repeat rotation, hit-point alignment, risers ending on the hit, releases after heavy hits, ducked under the voice). Override with `"sfx": "<id>"` or `"sfx": false` on an effect, or `--sfx off`. `--bed-start` sets where a music bed begins. The locked cut-seam set is unchanged.
- **Music bed library.** 11 of our own tracks (made with Suno) in `kit/music/`, loudness-matched to -13 LUFS so `bedVol` 0.16 fits every one. Use one by name: `--bed vinyl-sunrise` or `"bed": "vinyl-sunrise"`. `npm run music` lists them; `npm run music:add -- <file>` adds a track (two-pass loudnorm, checked after conversion). `npm run check` flags an unknown bed or a library bed whose audio is missing; `music:add` refuses a name already in the library unless you pass `--replace`.
- **Kinetic captions by default.** Every spoken word animates in; key words go big in the display font and accent colour; an optional script accent. `--look kinetic|muse|classic`, `--style kinetic|pill|hormozi|karaoke|classic`. `"captionStyle": "classic"` keeps the old look.
- **Kinetic titles behind the head.** One per beat, 7 entrances, no repeats, flicker on the hook and payoff only. The person is cut out with `kit/mask.py`. `--no-titles`, `--no-mask`.
- **One cut-out for titles and effects.** `--mask birefnet|birefnet-portrait|mediapipe` on `npm run fx` (default: the job's `maskModel`) gives the effects pass the same rembg matte and cleanup the title mask uses, from `kit/mask_refine.py`. GPU through ONNX Runtime (DirectML on Windows), raw mattes cached per frame, `birefnet-portrait` added as the best-edge model. MediaPipe that cannot load (Windows Smart App Control) falls back to birefnet, for the titles (`kit/mask.py`) and for the effects pass (`effects/fx_runner.py`).
- **Effect layout on a tight shot.** `"face": <scale>` on any effect; `card_y` and `card_guard` on `pastel-word`; `rabbit-hole` no longer ghosts across the face while it fades.
- **Bed ducking controls.** `bedDuckRatio`, `bedDuckLead` (the dip starts before each word), `bedFadeOut`; a job's own sound files through `"sounds"`.
- **BiRefNet person mask.** `kit/mask.py --model birefnet` (or `npm run reel -- --mask birefnet`, or `"maskModel": "birefnet"` in `cut.json`) uses rembg with the birefnet-general-lite weights (MIT, downloaded on first use into rembg's cache, ~214 MB, not in git). Cleanup from the v3.1 hero reel (hole fill, speck removal, guided edge refine, flow-guided temporal smoothing, light erode + feather) runs on both backends; `--person person.mkv` writes an edge-decontaminated BGRA layer. MediaPipe stays the default (fast) so drafts and `npm run smoke` stay quick and never download the weights. `npm run effects:setup` installs rembg + onnxruntime (~390 MB of packages, Python 3.11+); `npm run effects:setup -- --birefnet` also fetches the weights.
- **Font pairing cycle.** `--fonts literata,bricolage,michroma` cycles the pairings through one reel: each kinetic title takes the next one, and captions, stickers and pills take the pairing of the title they sit under. A pairing is always applied whole, so a phrase never mixes two combos.
- **Eleven more font pairings.** `literata`, `bricolage`, `pirata`, `michroma`, `redhat`, `jakarta`, `grotesk-times`, `avantgarde`, `recoleta`, `haas`, `wabbit`. The first six are the exact free fonts (Archivo Black + Literata, Bricolage Grotesque + Gloock, Pirata One + Nunito Sans, Michroma + Cardo, Red Hat Display + Red Hat Mono, Plus Jakarta Sans + Ribeye); the last five are free stand-ins for commercial pairs. 16 font files, 3.8 MB, each with its licence. Example stills for all 15 pairings and a cycle loop in `kit/fonts/examples/` (`npm run fonts:examples`).
- **Font pairings as lockups.** `--fonts modern|druk|elegant|editorial` (OFL Google Fonts, committed with their licences), or your own in the gitignored `kit/fonts/local/`. Each title and kinetic line sets the hero word big in the display face and the rest of the phrase in the partner face, arranged per pairing (stack, overlap, inline). Titles fill about 90% of the safe width; on caption lines the partner runs 55 to 65% of the hero with a legible floor (46 px sans, 60 px script). `"hero"` per phrase in `captions.js` or `cut.json`; `"lockup": false` for one font. `build/lockups.json` lists every lockup.
- **Multi-take picking.** `clip.py` takes several files, matches sentences across takes and keeps the best one; `--hook <take>`. `npm run reel` uses every video from the newest session in `inbox/`.
- **Zoom punch.** 10% on every other cut, plus a 12% eased big punch after the hook and into the payoff. `"punch"`, `"bigPunch"`, `"zoom"`, `"punchY"`, `--no-punch`.
- **Named transitions.** 50 names mapped to ffmpeg xfade modes in `kit/transitions.json`. The glitch seam stays the default.
- **Sound rules.** Locked set `whoosh`, `swipe`, `boom`, `click`, `typing` (mono 48 kHz WAV, CC0). Fewer and deeper; `npm run check` flags a sound on every cut.
- **`npm run check`** lints copy (em dashes, "not X but Y", staged run-ups, hype words), titles, transitions, sounds and script shape.
- **`npm run verify -- <job>`**: ffprobe (1080x1920, 24 fps, H.264 + AAC 48 kHz, duration), loudness, title and punch stills, contact sheet, mask alpha, copy lint. Mandatory before delivery.
- Effects keep words and titles out of their way: `captions: off` hides them, `check` moves the caption track up.
- `effects/CATALOG.md` has an "Everything available" count.
- Fix: segments whose video ends a frame before their audio no longer leave gaps (and a variable frame rate) in the cut, and the tail and pad holds now actually add frames.
- Fix: `render.mjs` refreshes `build/overlay.html` from the kit on every run, so `--rebuild` and `--force` pick up kit changes (`KEEP_OVERLAY=1` keeps a hand-edited copy).
