# Changelog

## 1.3.0 (unreleased)

- **Teardown, then remake.** `npm run teardown -- <reel.mp4>` breaks a reference reel down with [rea-video](https://github.com/JuneYaooo/rea-video) (Apache-2.0; `--install` adds it) and maps the VIDEO.md breakdown onto the talking-head menu with `kit/videomd2reel.cjs`: caption style, up to 7 titles with the nearest entrance and a front/behind hint from the person mask, a finish per shot from the grade, punches from cuts and zooms, beat sync and the closest library bed from the tempo, brand colours, and the reference's script. It writes `teardown/<name>/Reel.md`, a report of what was detected and why, and a labelled contact sheet. Then `npm run reel -- --recipe teardown/<name>/Reel.md --clip <your clip>` remakes it. Without rea-video, a lighter built-in analyzer (`kit/teardown.py`: frame-difference cuts, grade stats, rapidocr, faster-whisper, the beat grid) runs offline. Local files, plus an optional `--url <instagram post>` that fetches one named post anonymously with instaloader (MIT) when it is installed, into the gitignored `teardown-in/`; no login, no bulk. Captions shown one big word at a time are recognised as one-word even when the engine files them as labels. `--reuse` redoes only the mapping. Accuracy notes in `docs/teardown.md`.
- **Reel.md recipes.** A plain-Markdown, VIDEO.md-compatible recipe for a reel: brand kit, music and beat sync, finish per shot, shot list, titles with entrance and layer, caption style, effects (`docs/reel-md.md`). `npm run reel -- --recipe <Reel.md> --clip <file>` applies it (flags win, then the recipe, then its preset). `npm run reelmd -- check|compile|export|package`: export turns any finished job back into a Reel.md, package writes a full VIDEO.md package. Three examples in `examples/recipes/`. Smoke covers the round trip, the recipe on a draft, and a fallback teardown of a synthetic reel.
- **One-line agent install and skills.** `INSTALL.md` is written for agents (clone, npm install, Python venv, check and smoke, then offer the menu). `npx skills add wrg32786/aigent-talking-head` installs four new skills: talking-head-reel, talking-head-recipe, talking-head-brand and talking-head-teardown.

- **Music beds are CC0 1.0.** The 11 tracks in `kit/music/` (made by Will Gwyn / The AIgent with Suno, on a paid plan) are dedicated to the public domain. Anyone may use them, including commercially. See [kit/music/LICENSE.md](kit/music/LICENSE.md). The demo-reel footage of Will Gwyn stays for The AIgent's own use.
- **Behind-head titles rest with the lower edge tucked.** Default `"titleY"` is 345 (the centre of the big word) so on a typical 9:16 talking-head most of the word stays readable and only its lower edge sits behind the hair. Showcase front vs behind stills are taken after the slam has risen, not during the mid-hold when the word was hidden.
- **Title layer is a per-title choice.** Titles sit in front of the person by default. Set `"layer": "front"|"behind"|"auto"` on a title in `captions.js`, or `"titleLayer"` on the job (`captions.js` or `cut.json`). Auto (used by the aigent and cinematic presets, and by `--preset auto` when the preset uses it) puts only the strongest 1 or 2 punch titles behind the head, never consecutive ones. Slam still lands low and rises when a title is behind. Agents offer front vs behind per title. `npm run check` and `npm run smoke` cover the default, an explicit behind title, and the auto cap.
- **Visual README.** The README now leads with a before/after loop of the demo reel (raw phone clip beside the finished edit) and labelled contact sheets of every effect, film finish, title entrance, caption style, font pairing and preset. A [full per-item gallery](showcase/GALLERY.md) renders on GitHub. `npm run showcase` rebuilds the sheets. The HTML gallery must be opened from a full clone or zip.

- **Offer the menu, and a labelled showcase.** The menu of finishes, looks, caption styles, fonts, themes, title entrances, transitions, 51 effects, SFX and music beds is easy to miss. Agents must show it before drafting and again before the final render (`AGENTS.md`, `skills/talking-head-ad/SKILL.md`): run `npm run menu` (every option, grouped, with a one-line label, sourced from the catalogs so a new entry cannot stay hidden), point at [showcase/index.html](showcase/index.html), suggest 2 or 3 options per category, and vary film finishes across scenes. `npm run showcase` generates the self-contained gallery from an AI-generated fictional presenter (`showcase/source/presenter.jpg`, Apache-2.0 with the repo; titles are composited behind the head with the person mask). `npm run check` and `npm run smoke` fail if the menu or the showcase omit a catalog entry.
- **Teal finish is a subtle teal-and-orange grade.** The `teal` film finish uses a low-strength colorbalance: a hint of teal only in deep shadows and background, midtones left alone so skin and fabric stay natural, and a light warm lift in the highlights. It replaces a curves pair that went purple/magenta, and a first pass that tinted hair and shirt a saturated blue. Aliases `teal-orange` and `teal_orange` still resolve to it.
- **Brand presets.** `npm run reel -- --preset <name>` applies a saved mix of theme, look, caption style, fonts, finishes (with a per-scene variety pool), transitions and favourites. Flags and `cut.json` fields you set win over the preset. `--preset auto` picks a shipped style and prints what it chose. Shipped: `aigent`, `one-word`, `hormozi-bold`, `karaoke`, `minimal-clean`, `cinematic`, `editorial`, `muse-pill`, `retro-scan-lines`, `neutral` (`kit/presets/`). User-saved presets go in the gitignored `kit/presets/local/`. `npm run preset -- --list|--show|--save <name> --from <job>`. Optional `npm run brand:import -- <pdf|image|markdown>` drafts a preset from a brand guide (k-means palette, named fonts, tone notes) for a human to confirm; no new heavy deps, and it falls back if pdftoppm/pdftotext are missing. Agents ask first: saved preset, customize, or let me choose.
- **One-word captions.** `--style one-word` (and `--look one-word`, or the `one-word` preset) puts exactly one word on screen at a time, punchy, in the display face, timed from the word list. While a title is up it is the one word: the title drops its partner line and the caption waits. `npm run check` and `npm run smoke` cover the new style.
- **Readable titles behind the head.** Titles now rest high (`"titleY"` in `captions.js`, default 345, the centre of the big word) so most of the word clears the head and only its lower edge can tuck behind the hair. The slam lands lower, behind the head (`"titleSlamY"`, default 600), holds, then eases up to the resting height with the mask applied every frame. `"titleRise": false` (per title or for the job) lands it at the resting height. The smaller partner words of a title now draw on the front layer, in front of the person, with a thin outline, so they are never hidden. `npm run smoke` checks the slam, the rise, the partner layer and one word on screen.

## 1.2.0 (unreleased)

- **Beat-sync and film finish.** When a music bed is set, `kit/beats.py` (librosa) writes `build/beat-grid.json` from the bed at `bedStart` for the reel length: tempo, beats, onsets, energy, and intensity-filtered drops. `"beatSync": true` (the default when a bed is set; `--no-beat-sync` to turn it off) snaps zoom punches, pack and locked-set SFX, fx hit points, and title entrances to the nearest beat or onset within 120 ms, and adds a short camera shake on strong drops (at most two per shot). Speech cuts and lip sync do not move. Optional `"finish"` on the cut or a segment applies an ffmpeg film look on the picture, before titles: `grain`, `vignette`, `chroma`, `scan-lines`, `warm`, `cool`, `teal`, `crushed`, `mono`, `bleach`. No LUT files or light-leak assets. Adapted from the author's music-video project and relicensed Apache-2.0. `npm run check` validates finish names; `npm run smoke` covers the snap rules and a finish render.
- **Public-ready sanitization.** AIgent is the default theme (`--theme neutral` for an unbranded offline look). The HeyGen retake example no longer includes account or asset ids.

Edit rules from the Muse reel workflow, plus parts of a motion design pack, adapted to 1080x1920 at 24 fps.

- **Cinematic SFX pack.** 31 Will-approved sounds in `kit/sfx/` (`sfx.json`), all CC0. `npm run fx` auto-picks one per effect hit (category map, no-repeat rotation, hit-point alignment, risers ending on the hit, releases after heavy hits, ducked under the voice). Override with `"sfx": "<id>"` or `"sfx": false` on an effect, or `--sfx off`. `--bed-start` sets where a music bed begins. The locked cut-seam set is unchanged.
- **Music bed library.** 11 of our own tracks (made with Suno) in `kit/music/`, loudness-matched to -13 LUFS so `bedVol` 0.16 fits every one. Use one by name: `--bed vinyl-sunrise` or `"bed": "vinyl-sunrise"`. `npm run music` lists them; `npm run music:add -- <file>` adds a track (two-pass loudnorm, checked after conversion). `npm run check` flags an unknown bed or a library bed whose audio is missing; `music:add` refuses a name already in the library unless you pass `--replace`.
- **Kinetic captions by default.** Every spoken word animates in; key words go big in the display font and accent colour; an optional script accent. `--look kinetic|muse|classic`, `--style kinetic|pill|hormozi|karaoke|classic`. `"captionStyle": "classic"` keeps the old look.
- **Kinetic titles behind the head.** One per beat, 7 entrances, no repeats, flicker on the hook and payoff only. The person is cut out with `kit/mask.py`. `--no-titles`, `--no-mask`.
- **One cut-out for titles and effects.** `--mask birefnet|birefnet-portrait|mediapipe` on `npm run fx` (default: the job's `maskModel`) gives the effects pass the same rembg matte and cleanup the title mask uses, from `kit/mask_refine.py`. GPU through ONNX Runtime (DirectML on Windows), raw mattes cached per frame, `birefnet-portrait` added as the best-edge model. MediaPipe that cannot load (Windows Smart App Control) falls back to birefnet, for the titles (`kit/mask.py`) and for the effects pass (`effects/fx_runner.py`).
- **Effect layout on a tight shot.** `"face": <scale>` on any effect; `"drop": <face widths>` moves what an effect draws behind the speaker down, so the head cuts into a behind-head word instead of the word floating above it; `card_y` and `card_guard` on `pastel-word`; `rabbit-hole` no longer ghosts across the face while it fades.
- **Bed ducking controls.** `bedDuckRatio`, `bedDuckLead` (the dip starts before each word), `bedFadeOut`; a job's own sound files through `"sounds"`.
- **BiRefNet person mask.** `kit/mask.py --model birefnet` (or `npm run reel -- --mask birefnet`, or `"maskModel": "birefnet"` in `cut.json`) uses rembg with the birefnet-general-lite weights (MIT, downloaded on first use into rembg's cache, ~214 MB, not in git). Cleanup from the v3.1 hero reel (hole fill, speck removal, guided edge refine, flow-guided temporal smoothing, light erode + feather) runs on both backends; `--person person.mkv` writes an edge-decontaminated BGRA layer. MediaPipe stays the default (fast) so drafts and `npm run smoke` stay quick and never download the weights. `npm run effects:setup` installs rembg + onnxruntime (~390 MB of packages, Python 3.11+); `npm run effects:setup -- --birefnet` also fetches the weights.
- **The oneword look.** `--look oneword`: one word on screen at a time, sized and faced by its role (small filler, body words, a big italic-serif hero with the phrase building under it), and type cards (mode 8: flat-colour cutaways with an optional giant numeral) as text-only b-roll. New `instrument` pairing (Instrument Serif Italic + Inter Tight). `build/oneword.json` lists every word's state; the smoke test checks it. Spec: `kit/looks/oneword.md`.
- **Legibility check.** Words on the picture in the oneword look get a soft dark glow and a thin dark edge. `kit/legibility.py` measures the contrast of every caption moment against the picture behind it in the finished reel and lists anything under 3:1; `npm run reel` runs it after each reel.
- **Two-pass assembly.** With a caption layer, `assemble.cjs` lays the captions and the glitch shake in a second pass at a constant 24 fps. One graph with captions, the person mask and inserts ran at a tenth of real time or less.
- **B-roll inserts.** `"inserts"` in `cut.json` (and `--broll <folder>` on `npm run reel`): your clips cut in over the picture for a span while the voice runs on, optionally black and white. `npm run check` checks the files and spans. The oneword look also puts a key word behind the head on its first and last beat, and sets words on shapes in the frame (`kit/anchors.py`: a hard line in a cutaway, the top of the speaker's head, a shoulder).
- **`backdrop-word` rebuilt.** Tall Anton type as wide as the frame, letters rising in one by one from behind the speaker, placed so the head cuts into the word.
- **Demo reel example.** `kit/example/demo-reel/`: a finished 40 s reel (720x1280 copy) with the `cut.json`, `fx.json` and `captions.js` that built it.
- **Font pairing cycle.** `--fonts literata,bricolage,michroma` cycles the pairings through one reel: each kinetic title takes the next one, and captions, stickers and pills take the pairing of the title they sit under. A pairing is always applied whole, so a phrase never mixes two combos.
- **Eleven more font pairings.** `literata`, `bricolage`, `pirata`, `michroma`, `redhat`, `jakarta`, `grotesk-times`, `avantgarde`, `recoleta`, `haas`, `wabbit`. The first six are the exact free fonts (Archivo Black + Literata, Bricolage Grotesque + Gloock, Pirata One + Nunito Sans, Michroma + Cardo, Red Hat Display + Red Hat Mono, Plus Jakarta Sans + Ribeye); the last five are free stand-ins for commercial pairs. 16 font files, 3.8 MB, each with its licence. Example stills for all 15 pairings and a cycle loop in `kit/fonts/examples/` (`npm run fonts:examples`).
- **Font pairings as lockups.** `--fonts modern|druk|elegant|editorial` (OFL Google Fonts, committed with their licences), or your own in the gitignored `kit/fonts/local/`. Each title and kinetic line sets the hero word big in the display face and the rest of the phrase in the partner face, arranged per pairing (stack, overlap, inline). Titles fill about 90% of the safe width; on caption lines the partner runs 55 to 65% of the hero with a legible floor (46 px sans, 60 px script). `"hero"` per phrase in `captions.js` or `cut.json`; `"lockup": false` for one font. `build/lockups.json` lists every lockup.
- **Multi-take picking.** `clip.py` takes several files, matches sentences across takes and keeps the best one; `--hook <take>`. `npm run reel` uses every video from the newest session in `inbox/`.
- **Zoom punch.** 10% on every other cut, plus a 12% eased big punch after the hook and into the payoff. `"punch"`, `"bigPunch"`, `"zoom"`, `"punchY"`, `--no-punch`.
- **Named transitions.** 50 names mapped to ffmpeg xfade modes in `kit/transitions.json`. The glitch seam stays the default.
- **Sound rules.** Locked set `whoosh`, `swipe`, `boom`, `click`, `typing` (mono 48 kHz WAV, CC0). Fewer and deeper; `npm run check` flags a sound on every cut.
- **`npm run check`** lints copy (em dashes, "not X but Y", staged run-ups, hype words), titles, transitions, sounds and script shape.
- **`npm run verify -- <job>`**: ffprobe (1080x1920, 24 fps, H.264 + AAC 48 kHz, duration), loudness, title and punch stills, contact sheet, mask alpha, copy lint. Mandatory before delivery.
- Effects keep words and titles out of their way: `captions: off` hides them, `check` moves the caption track up.
- `effects/CATALOG.md` has an "Everything available" count.
- Fix: segments whose video ends a frame before their audio no longer leave gaps (and a variable frame rate) in the cut, and the tail and pad holds now actually add frames.
- Fix: `render.mjs` refreshes `build/overlay.html` from the kit on every run, so `--rebuild` and `--force` pick up kit changes (`KEEP_OVERLAY=1` keeps a hand-edited copy).
