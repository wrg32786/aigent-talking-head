# Source

`SKILL.md` and `LICENSE` in this folder are copied unchanged from [blader/humanizer](https://github.com/blader/humanizer) by Siqi Chen, MIT License, at commit [`a32f24407364c74c812b43c15926d638bee1e072`](https://github.com/blader/humanizer/tree/a32f24407364c74c812b43c15926d638bee1e072) (skill version 4.0.0).

This kit uses it to make scripts read like a person talking: agents run it on every script draft before `write_script` saves it, unless they already have an equivalent humanizer skill installed. Studio's API and local model chat follows a short summary of its rules (`HUMANIZER_RULES` in `kit/studio/scripts.mjs`).

To update, copy `SKILL.md` and `LICENSE` from a newer commit and change the commit above.
