# aigent style pack

The default look as a pack. Every word animates, one kinetic title per beat, a glitch seam on most cuts and grain or vignette varied across scenes.

![aigent pack preview](preview.webp)

Use it: `npm run reel -- inbox/take.mov --pack aigent`

- Base preset: aigent
- Locks: transitions glitch, whip, zoom; finishes grain, vignette
- Version 1.0.0, Apache-2.0, by AIgent

Copy it to make your own: `npm run pack:new -- my-look --from aigent`. The format is in [docs/packs.md](../../docs/packs.md).
