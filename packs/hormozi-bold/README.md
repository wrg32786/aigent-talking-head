# hormozi-bold style pack

High energy. Caption words in bold caps with the active word lit, titles that slam or pop, and hard, fast seams.

![hormozi-bold pack preview](preview.webp)

Use it: `npm run reel -- inbox/take.mov --pack hormozi-bold`

- Base preset: hormozi-bold
- Locks: transitions glitch, whip, zoom, flash; titles slam, pop-zoom, elastic, drop; finishes grain, crushed
- Version 1.0.0, Apache-2.0, by AIgent

Copy it to make your own: `npm run pack:new -- my-look --from hormozi-bold`. The format is in [docs/packs.md](../../docs/packs.md).
