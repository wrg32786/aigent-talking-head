# cinematic style pack

A film grade that varies across scenes, soft film cuts and dips to black, and titles that rise or type in rather than slam.

![cinematic pack preview](preview.webp)

Use it: `npm run reel -- inbox/take.mov --pack cinematic`

- Base preset: cinematic
- Locks: transitions film, dissolve, dip-black, fade-slow; titles blur-rise, drop, typewriter, stagger-rise; max 4 titles; finishes teal, grain, vignette, crushed
- Version 1.0.0, Apache-2.0, by AIgent

Copy it to make your own: `npm run pack:new -- my-look --from cinematic`. The format is in [docs/packs.md](../../docs/packs.md).
