# magazine style pack

Common short-form editing advice as one look: placed titles around the head, olive and cream cards, energy-matched music, sparse mapped sounds and no dead air.

![magazine pack preview](preview.webp)

Use it: `npm run reel -- inbox/take.mov --pack magazine`

- Base preset: magazine
- Locks: transitions crossfade, dissolve, fade-fast; titles typewriter, blur-rise, pop-zoom, stagger-rise, slide-left, drop; max 6 titles
- Version 1.0.0, Apache-2.0, by AIgent

Copy it to make your own: `npm run pack:new -- my-look --from magazine`. The format is in [docs/packs.md](../../docs/packs.md).
