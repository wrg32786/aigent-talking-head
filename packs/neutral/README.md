# neutral style pack

No brand colours or logo. A safe start for your own pack: npm run pack:new -- my-look --from neutral.

![neutral pack preview](preview.webp)

Use it: `npm run reel -- inbox/take.mov --pack neutral`

- Base preset: neutral
- Locks: transitions cut, crossfade; finishes none
- Version 1.0.0, Apache-2.0, by AIgent

Copy it to make your own: `npm run pack:new -- my-look --from neutral`. The format is in [docs/packs.md](../../docs/packs.md).
